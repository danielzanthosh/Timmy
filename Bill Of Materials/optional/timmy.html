Firmware Installation

Flash Timmy in
four steps.

Timmy Firmware v1.0.0

Pre-built .bin for ESP32-C3 Super Mini · MicroPython runtime included

Download .bin
01
Install esptool
You'll need Python 3 and pip installed. Then grab esptool from PyPI:
pip install esptool
02
Erase Flash
Hold the BOOT button while plugging in the ESP32-C3 via USB-C, then erase existing firmware:
esptool.py --chip esp32c3 \
--port /dev/ttyUSB0 \
erase_flash
On Windows, replace /dev/ttyUSB0 with your COM port (e.g. COM5).
03
Flash the Firmware
Run the write command pointing to the downloaded .bin:
esptool.py --chip esp32c3 \
--port /dev/ttyUSB0 \
--baud 460800 write_flash \
-z 0x0 timmy_v1.0.0.bin
04
Connect & Configure
Power cycle the board. Timmy will broadcast a Wi-Fi AP named Timmy-Setup. Connect to it and navigate to 192.168.4.1 in your browser to open the web dashboard and configure your home Wi-Fi and Pomodoro settings.
